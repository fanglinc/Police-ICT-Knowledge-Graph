# 🚔 《公安信息化应用基础》公安知识图谱与警务能力画像

> **一个面向教学改革与成果汇报的“零代码/全静态”可视化轻量化平台。**
> 仅需一个 HTML 文件即可在 PC、平板、手机端完美流畅运行，自带警务科技风 UI 与 ECharts 力导向图交互。

## ✨ 项目核心亮点（用于汇报时提炼）
- **真实场景驱动：** 以 6 大公安业务场景为骨架，重构课程内容，实现真正的“OBE（成果导向）”落地。
- **能力画像具象：** 构建 8 维警务能力模型，精准刻画本课程对学生核心能力的培养层级与贡献度。
- **思政元素图谱化：** 创新性地将课程思政由“空洞口号”转化为 6 大主题、18 个具体素养标签，并映射至项目板块 (P1-P6)。
- **公安特色 UI：** 深度融合指纹、足迹、六边形 HUD、线框立方体等刑技与科技元素，视觉冲击力强。

## 📁 文件结构
- `knowledge_graph.html`：包含全部前端代码、数据逻辑与 UI 设计的主文件。
- `echarts.min.js`：ECharts 5.x 图表引擎本地库文件（放置同目录下，支持内网/离线演示）。

## 🖥️ 如何部署与使用？
1. **直接打开：** 确保 `echarts.min.js` 和 `knowledge_graph.html` 在同一文件夹内，双击 HTML 即可。
2. **局域网/内网部署：** 将整个文件夹放置于服务器或共享盘。
3. **手机端查看：** 将文件上传至 GitHub 后，开启 GitHub Pages 服务，或直接通过微信/企业微信发送 HTML 文件，用浏览器打开。

## 💡 技术栈
- HTML5 / CSS3 / JavaScript (原生，无框架依赖)
- Apache ECharts 5.x (力导向图)
- 响应式布局（移动端自适应）

## 🖌️ 设计语言（视觉提炼）
采用“警务深空蓝+赛博青+警示红”作为核心主色调。背景辅以刑侦技术元素水印（指纹、足迹、放大镜、DNA），构建出符合公安院校纪律严明、科技强警的教学氛围。

## 四、字色规范（深底亮字，保证对比分明）

| 元素 | HEX | 字号（建议） |
|---|---|---|
| 一级标题（h1） | `#eaf2ff` | 24–28px |
| 二级标题（h2） | `#22d3ee` | 18–20px |
| 三级标题（h3） | `#60a5fa` | 16–18px |
| 正文 | `#eaf2ff` | 14–16px |
| 副文字 / 标签 | `#9db4d8` | 12–14px |
| 极弱文字（提示） | `#6f86ad` | 12px |
| 链接 / 强调文字 | `#22d3ee` | — |
| 警示 / 红色文字 | `#f87171` | — |

> **深空霓虹版铁律**：深蓝底上**禁止**使用深色文字（如 `#0f172a`、`#1e3a8a`），所有文字必须是 `#eaf2ff` 一系亮色，否则不可读。浅色版与深色版的文字色相反，切换时务必整版替换。
